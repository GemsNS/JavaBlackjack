### Project Idea (Simple Overview)
I propose to build a one-file Java console game called **Console Blackjack Trainer**.
The player will play against a computer dealer using text commands.
The game will focus on clean logic, readable code, and full use of course concepts.

### Why This Project
- It is simple enough to finish on time.
- It is still creative because it uses game rules and decision making.
- It gives many chances to show loops, conditionals, methods, and lists.
- It can include clear comments and documentation for grading.

### Planned Features
- Start a new round and deal cards.
- Player can choose actions like hit or stand.
- Dealer follows fixed blackjack rules.
- Scores are calculated and winner is shown.
- Invalid input is handled safely with `try-catch`.

### How This Meets Project Requirements
- **Input/Output:** `Scanner` will read commands from the keyboard, and the game will print results to the console.
- **Control Structures:** The program will include multiple `if-else` statements and at least two loops (`while` and `for`).
- **Methods:** The program will use more than three custom methods (for example: deal cards, calculate hand value, dealer turn, show results).
- **Arrays/ArrayLists:** `ArrayList` will store cards for the deck, player hand, and dealer hand.
- **Error Handling:** `try-catch` will handle bad or unexpected user input.


### Expected Outcome
By finishing this project, I will show practical understanding of Java basics in one complete, working program that matches the rubric and class requirements.
